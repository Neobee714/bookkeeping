# v0.9 需求：四套可选主题（UI 重设计落地）

- 创建时间：2026-10-23
- 前置：v0.8 离线能力（2.3.0 / 223）
- 预览稿：`docs/v0.9/preview/ui-styles.html`（10 个方向的完整对比）

## 背景

现有视觉只有一套「活力渐变」。UI 重设计评审后，从 10 个方向中选定 4 套作为可切换主题。
本轮只改视觉层，任何功能、字段、请求、状态机都不动。

## 范围

皮肤：04 柔和浮雕 Neu、06 暗夜霓虹 Neon、08 糖果马卡龙 Candy、10 流动极光 Aurora。

## 功能需求

| 编号 | 需求 |
| --- | --- |
| FR-01 | 「我的」新增「外观」入口：4 张预览卡 + 模式选择（跟随系统 / 亮色 / 深色） |
| FR-02 | 选择持久化到 AsyncStorage，冷启动恢复；首帧不闪默认皮肤 |
| FR-03 | 04 锁定亮色、06 锁定深色；08 / 10 支持跟随系统、亮、暗 |
| FR-04 | 切换即时生效：页面、Tab、导航、状态栏、弹窗、登录页同步换肤 |
| FR-05 | 记一笔的收支切换、分类选中、保存按钮在新皮肤下保持可读 |
| FR-06 | 首页月份卡在 04 下为浅浮雕、10 下为极光渐变、08 糖果渐变、06 深色发光 |

## 非功能需求

| 编号 | 需求 |
| --- | --- |
| NFR-01 | 不新增原生依赖；不使用位图纹理；不内嵌字体 |
| NFR-02 | 阴影只用 `boxShadow`（RN 0.87 新架构），列表行不用阴影，保证滚动帧率 |
| NFR-03 | 深色主题正文对比度 ≥ 4.5:1；次要文字 ≥ 3:1 |
| NFR-04 | 切换主题不发请求、不重置页面状态、不重启 |
| NFR-05 | 皮肤以注册表组织，后续加 01/02/03/05/07/09 只需新增一个文件 |

## 验收标准

1. 四套主题在首页 / 图表 / 规划 / 小光 / 我的 / 记一笔 / 分类管理 / 管理后台 / 登录 / 注册 / 更新弹窗上没有白块、错色、不可读文字。
2. 04 在系统深色下仍是亮界面且状态栏为深色图标；06 反之。
3. 杀进程重启保持上次选择。
4. `tsc --noEmit` 0 错；`jest` 全过；`eslint` 不高于改动前 baseline。
5. vivo V2339A 真机：四套各走一遍记账 / 编辑 / 长按删除 / 切月 / 伴侣视图 / 图表 / 记一笔。

## 明确不做

- 其余六套（01/02/03/05/07/09）本轮不做，但注册表与 token 预留
- 主题商店、自定义取色、按时间自动切换
- 任何接口、数据、导航结构调整
