# v0.21 需求：图表分类/商家明细页（按备注看支出）

来源：用户 2026-11-17 需求 + 样例确认（`docs/v0.21/preview/category-detail-sample.html`）。
版本线：2.9.2 → 2.9.3（versionCode 238 → 239）。纯 `mobile/`，无后端改动。

## FR-1 图表页入口

- FR-1.1 「支出分布」的**分类行**整行可点，右侧显示 ›，按压有反馈；点击进入分类明细页。
- FR-1.2 「商家」档的行同样可点进入明细页（同一页面，按商家过滤）。
- FR-1.3 进入时携带：dimension（category/merchant）、name、month（YYYY-MM）、tab（self/partner）。

## FR-2 分类明细页（RootStack 压栈页）

- FR-2.1 顶部：‹ 返回 + 标题（分类/商家名）；继承图表页的月份与我的/伴侣档位（页面内展示为「2026年11月 · 我的账本」）。
- FR-2.2 汇总卡：该分类本月合计、笔数、占本月支出比例、日均、笔均。
- FR-2.3 「明细 / 备注」两档切换；默认「明细」。
- FR-2.4 明细档：按日期倒序分组的账单列表（日期头 + 当日小计），行样式复用 TransactionItem（商家主标题、备注副标题、无商家显示分类）；只读（点击无操作）。
- FR-2.5 备注档：按备注聚合并按金额降序：备注名、金额、次数、平均；点击展开该备注下的账单（日期 · 商家，金额）；未填备注归入「未备注」；脚注说明聚合口径。
- FR-2.6 加载态/错误态/空态齐全；错误态提供重试；伴侣未绑定时按现有 403 语义提示。
- FR-2.7 数据：先用整月账单离线缓存渲染，再拉取接口覆盖并写回缓存（与首页同 key）。**不新增后端接口。**

## 非目标

- 不做出入账类型以外的统计（明细页只看支出）；不做导出/跨月；明细行不接编辑；不动 /stats 接口。

## 验收标准

1. 图表页点「餐饮」→ 明细页标题餐饮、汇总与图表行金额一致（样例口径）。
2. 明细/备注切换正确；备注展开/收起正确；备注聚合金额合计 = 分类合计。
3. 伴侣档进入时展示伴侣数据；切回图表页状态不丢。
4. 本地门禁：`npx tsc --noEmit && npx jest && npx eslint .`（仅新增告警对照）。
5. 新增纯函数单测覆盖：过滤、日期分组、备注聚合、日均天数。

## Q&A

| 问题 | 结论 |
| --- | --- |
| 商家档是否也可点？ | 是，复用同一页（样例假设第 3 条，用户确认「就按照这样」） |
| 明细行可点编辑？ | 否，只读（样例假设第 4 条） |
