# v0.23 微信 / 支付宝账单导入

## 目标

把微信支付、支付宝导出的账单文件导入拾光，做到「选文件 → 看预览 → 一键入账」，重复导入不重复入库，分类尽量自动推断。

## 功能需求

- **FR-1 格式识别**：上传 zip / xlsx / csv，自动识别微信支付账单（xlsx 与 csv）、支付宝账单（csv）、拾光旧版 CSV。编码自动识别 UTF-8 / GBK。
- **FR-2 zip 解压**：微信账单 zip 为 ZipCrypto + 6 位数字密码。服务端优先用 6 位穷举（10^6，<1s），不要求用户填写；支付宝等固定密码失败时可退回用户手填。
- **FR-3 预览**：解析结果先返回预览，不落库。每行给出日期、金额、收支、商家、备注、建议分类、是否已存在；被跳过的行单独列出原因。
- **FR-4 跳过策略**：中性交易（提现/零钱通）、退款原单与退款行、转账/红包默认跳过并计入统计说明，避免虚增收支。
- **FR-5 去重**：以「来源:交易单号」作为 `client_id`，重复导入时已存在的行标记为已存在，提交时跳过。
- **FR-6 分类推断**：内置商家/关键词规则 → 用户规则表 → 兜底分类。用户可自定义分类，规则按分类名匹配，因此自定义分类同样可被规则命中。
- **FR-7 学习规则**：用户在预览里改分类时可勾选「以后这个商家都用这个分类」，提交后写入 `import_rules`，下次自动命中。
- **FR-8 提交**：只写入用户确认过的行；类别不存在时回落；返回导入数、重复数、学习规则数。

## 非目标

- 不做邮箱自动收件（二期）。
- 不做无障碍读微信界面。
- 不在本轮发布 APK / 推送后端。

## 验收

- 用真实微信账单（166 笔）导入测试账号：可入账 120 笔、跳过 46 笔（退款/中性/转账），金额与账单抬头一致。
- 同一文件重复提交：新增 0 笔。
- 自定义分类（如「水」「小摔炮」）可被规则命中并写入。
