# v0.17 需求：财报总结（个人账本）

- 创建时间：2026-11-12
- 起点版本：2.6.1 / versionCode 232
- 目标版本：2.7.0 / versionCode 233
- 样例：`docs/v0.17/preview/report.html`（用户已确认方向，并要求：仅个人账本、兼顾全部主题）

## 背景

现在只能按月看收支汇总，没有一个「像财报一样」的阶段性结论。用户希望自己配置报告周期
（周报 / 月报 / 季报 / 年报）和生成时间，由服务端在周期结束后自动生成，App 内查看历史报告。

## 已确认的范围

- **仅统计个人账本**：报告只读当前用户自己的账单，不读取伴侣数据，不做双人对比。
- **报告周期**：周报 / 月报 / 季报 / 年报四种，覆盖「上一个完整自然周期」。
- **生成时间可配**：周报选星期几 + 时点；月报 / 季报 / 年报选每月 1–28 日 + 时点。
- **主题适配**：所有颜色取自现有 skin token，四套皮肤（极光 / 糖果 / 霓虹 / 浮雕）与亮暗模式均可读。
- **不推 OTA**：本轮只完成实现与本地门禁，构建、发布、OTA 等用户下一步指示。

## 功能需求

- **FR-01 生成设置**：可配置周期类型、生成日（周报：周一–周日；其余：1–28 日）、生成时点
  （0–23 时，App 提供 08/09/12/20/21 常用项）、启用开关。每用户最多一条设置。
- **FR-02 自动生成**：服务端每小时检查一次；到达设置时点后生成「最近一个已完整结束」的周期报告。
  容器停机错过时点，恢复后只补最近一期，不批量刷历史。
- **FR-03 幂等**：同一用户 + 同一周期类型 + 同一周期只保留一份报告；重复执行不新增。
- **FR-04 立即生成**：设置弹层提供「立即生成上一期看看」，按当前周期类型生成最近一期；
  已存在时直接返回已有报告，不覆盖。
- **FR-05 报告列表**：按生成时间倒序；每条展示周期标签、起止日期、收支结余、笔数、未读标记；
  顶部展示当前规则与下次生成时间。
- **FR-06 报告详情**：结余 / 储蓄率、收入、支出、笔数、环比、自动洞察、支出分类分布、
  周期内趋势、最大单笔支出；数据快照在生成时固化，后续改账不影响历史报告。
- **FR-07 未读与入口**：图表页标题右侧「📄 财报」入口；有未读报告时显示红点与顶部提示条。
  打开详情即标记已读；列表接口返回未读总数。
- **FR-08 隐私**：报告只属于当前用户；访问他人报告返回 404；伴侣不可见。
- **FR-09 离线降级**：列表与已看过的详情离线读缓存并提示；设置、生成、标已读需要联网，
  失败不阻塞记账主流程。
- **FR-10 空数据**：周期内没有任何账单时，报告仍可生成，展示「本期还没有记账」态，不报错。

## 非功能需求

- 生成失败只记日志，不影响 API 主流程；调度循环内部捕获异常。
- 所有时间按 **Asia/Shanghai** 计算与展示；服务端容器时区为 UTC，不得依赖系统本地时区。
- 报告聚合只查当前用户，SQL 必须带 `user_id` 条件；不新增跨用户查询。
- 新接口失败必须静默降级，首页 / 图表主流程不受影响。
- 主题：禁止页面写死颜色；hero 用 `skin.heroGradient ?? [card, card]` 与 `onHero/onHeroMuted`，
  卡片用 `skin.surfaces.card`，柱状图用 `colors.primary` / `colors.income` / `colors.expense`。

## 验收标准

1. 默认设置为月报、每月 1 日 09:00、未启用；`next_run_at` 为空。
2. 启用「月报 · 每月 1 日 09:00」后，`next_run_at` 为下一个 1 日 09:00（北京时间）；
   把当前时间推进到该时点，生成上月报告，且第二次执行不再新增。
3. 周报生成覆盖上一个周一至周日；月报覆盖上一个自然月；季报覆盖上一个自然季度；年报覆盖上一年。
4. 同一周期重复调用生成接口 / 调度重复执行，报告数量不变。
5. 伴侣有账单时，报告的收入、支出、分类、笔数只包含本人数据。
6. 报告详情数字与同期 `/stats/monthly-summary?start_date=…&end_date=…` 对本人数据一致。
7. 已读接口把 `read_at` 置为当前时间；列表未读数相应减一。
8. 离线打开列表显示缓存；设置按钮置灰且不崩溃。
9. 四套皮肤下报告列表 / 详情 / 设置弹层无写死浅色底、文字与背景对比可读，亮暗模式正常。
10. `pytest`、`tsc --noEmit`、`jest`、`eslint` 全部通过（eslint 仅允许既存基线）。

## 不在本次范围

- 系统推送 / 本地通知、报告分享、导出 PDF / 图片。
- 自定义周期长度（近 30 天、每两周等）、跨周期对比图表。
- 双人合并报告、家庭成员维度。
- 报告生成后的手动编辑或删除。
- APK 构建、OTA 发布与线上部署（用户明确「不慌推出 OTA」）。
