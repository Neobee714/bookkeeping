# 2.8.1 补丁：循环记账即时同步 + 项目文案

版本：**2.8.1 / versionCode 235**（补丁，基于 2.8.0）

## 用户反馈

1. 循环记账没有和账单同步：新建循环规则后，账单列表看不到对应账单。
2. 账单里的字段不一定都是「吃了什么」，也可能是「玩了什么」，需要改文案。

## 修复

### 1. 循环记账立即落账

- `POST /recurring`、`PATCH /recurring/{id}` 保存后立即调用 `generate_rule_now`：
  如果规则今天到期，马上生成今天的账单，不再等每小时调度。
- 只处理当前规则，不顺手补其它规则；历史回溯仍受 90 天窗口限制。
- 创建时 `next_run_date` 使用**北京时间** `beijing_today()`，不再用容器 UTC 的 `date.today()`。
- 调度器 `generate_due` 也改用北京时间，避免 00:00–08:00 生成日期偏移。

### 2. 首页同步

- `HomeScreen` 从其它 tab 返回时静默刷新账单与汇总。
- App 从后台回到前台（`AppState=active`）时再刷新一次。
- 循环记账在服务端生成后，切回首页即可看到，不必手动下拉或重启。

### 3. 项目字段文案

- 餐饮 / 零食：`吃了什么`
- 娱乐：`玩了什么`（占位：电影 / 桌游 / 演唱会）
- 购物：`买了什么`
- 交通 / 旅游 / 医疗 / 教育 / 居住 / 收入 / 自定义分类：`项目`
- 整理旧备注页的选项与字段统一改为 `项目`；不再对所有旧备注假设是食物。
