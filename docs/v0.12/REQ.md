# v0.12 需求：分类刷新与记账弹层滚动

- 创建时间：2026-10-25 23:20
- 版本：2.4.3 / versionCode 227

## 1. 问题

1. 在分类管理里新增分类后，打开「记一笔」，新分类不出现；必须把 App 从后台清掉重开才出现。
2. 分类较多（约 4-5 行）时，记账弹层里选完一个分类后无法继续向下滚动到后面的分类。

## 2. 根因

### 2.1 新分类不刷新

- `CategoryScreen` 新增/编辑/删除后只刷新自己的列表，没有更新
  `bk.cache.v1.<userId>.categories` 缓存。
- `AddTransactionSheet` 用 `categoriesLoaded` 做一次性门闩：第一次打开后不再请求；
- `HomeScreen` 只在挂载时拉分类，从分类管理返回时不会重新拉。
- 因此弹层一直用旧缓存/旧 state，重启 App 才会重新走首屏加载。

### 2.2 分类多时不能下滑

- 弹层 `sheetWrap` 没有 `flex:1`，`sheet` 的 `maxHeight: 92%` 没有可靠的父高度；
  `ScrollView` 没有 `flexShrink`，内容多时被撑开而不是变成可滚动区域。
- Android 端 `KeyboardAvoidingView` 仍然是 `behavior={undefined}`，edge-to-edge 下
  键盘不会把弹层顶上去，下面几行分类被键盘盖住，看起来像“划不动”。

## 3. 需求

- FR-01：分类新增/编辑/删除后，回到首页或再次打开记账弹层，分类列表立即是最新的。
- FR-02：分类缓存同步更新，离线时打开弹层也能看到上次拉到的分类。
- FR-03：分类 4-5 行时，弹层可正常向下滚动到任意分类；键盘弹出时弹层缩短，
  下方分类仍可通过滚动选择。
- FR-04：不重复请求：弹层每次打开拉一次分类即可，选择分类不触发请求。

## 4. 验收

- 新增分类 → 返回首页 → 打开记一笔：新分类在列表中（无需重启）。
- 新增分类 → 杀进程重开（离线）→ 打开记一笔：新分类仍在缓存中。
- 分类 4-5 行：从第一行滑到最后一行并选中；键盘打开时也能滑到后面的分类。
- `tsc` 0 错误、jest 全过、release APK 可安装。
