# v0.13 需求：首页语音记账（方案 B）

- 创建时间：2026-10-25 23:35
- 版本：2.5.0 / versionCode 228
- 交互：首页右下角 + 号，**单击 = 手动记账**，**长按 = 语音记账**。

## 1. 背景与选择

- 用户选择方案 B：从首页直接语音记一笔，不先进入小光。
- 语音识别使用 **系统识别**（Android SpeechRecognizer），不新增后端、不接云端 ASR。
- 解析使用本地规则（金额/日期/分类），不调用大模型，不产生额外费用。
- 解析结果必须打开「记一笔」确认页，用户确认/修改后才入账。
- 第一版只记给自己；给伴侣记账需要改后端接口，暂不做。

## 2. 功能需求

- FR-01：首页 + 号长按（约 380ms）打开语音弹层；单击行为不变，仍打开手动记账。
- FR-02：语音弹层请求麦克风权限，使用系统语音识别，实时显示部分转写。
- FR-03：说完后自动结束或点「说完了」，把转写解析成账草稿：
  - 金额（支持“十八”“一百八”“5,000”等）
  - 收支类型（工资/收入/报销等识别为收入）
  - 分类（优先用户自定义分类名，其次常见关键词）
  - 日期（今天/昨天/前天/大前天/明天、M月D日）
  - 备注（去掉金额/日期后的原话）
- FR-04：解析成功后关闭语音弹层，打开「记一笔」并预填草稿，顶部显示
  「🎤 语音识别结果，请确认后保存」；用户可改金额/分类/日期/备注后再保存。
- FR-05：金额缺失时提示「没听清金额，请带上金额再说一次」，提供「重说」。
- FR-06：权限被拒、系统无语音服务、网络/识别失败都要有中文提示；不阻塞手动记账。
- FR-07：iOS 暂不开放语音（提示手动记账），Android 正常。

## 3. 非功能需求

- 不上传音频到自己的服务器；音频由系统语音服务处理。
- 不改后端、不改数据库、不改 OTA 清单契约。
- 语音失败不能影响手动记账与离线队列。
- 录音权限只在打开语音弹层时请求。

## 4. 验收

- 长按 + 号 → 说话「早餐十八块」→ 自动出现记一笔，金额 18、分类餐饮、
  日期今天、备注早餐；确认后落库。
- 说「昨天打车花了35」→ 日期昨天、金额 35、分类交通。
- 说「发工资5000」→ 收入、金额 5000。
- 单击 + 号仍然直接打开手动记账。
- 拒绝麦克风权限 → 提示去设置；取消后手动记账正常。
- `tsc` 0 错误、jest 全过、release APK 可安装。
