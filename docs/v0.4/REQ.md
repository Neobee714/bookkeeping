# 需求文档：金流 v0.4 迭代（圈子下线 / 首页吸顶 / 备注图表 / 改名 / Agent 收支 / 记账表单 / 个人资料 / 访问加速）

- 创建时间：2026-08-16 17:24
- 版本：v0.4
- 状态：已确认

## 1. 背景与目标

「金流」（原双人记账）v0.3 已上线 2.0.2。本轮为一次综合性迭代，共 10 项需求：
删除不再使用的圈子功能、优化首页与新增账单表单交互、图表页增加按备注维度的统计图表、
App 更名、修复内置 Agent 查不到收入账单的问题、完善「我的」页个人资料管理，
并调研中国大陆访问慢的解决方案。

目标：一次迭代内全部落地，发布 v2.1.0。

## 3. 非功能需求

- 兼容性：延续 RN 0.8x + Android minSdk 24；新增依赖需与现有 RN 版本兼容。
- 安全：修改密码需验证旧密码；头像上传沿用现有 base64 data URL 限制（≤200000 字符）；用户名唯一性由后端校验。
- 性能：按备注聚合接口需支持按月窗口查询，数据量级小，无需分页；排行/趋势图表沿用现有手写 SVG 方案，不引入重量级图表库。
- 删除圈子不破坏既有数据库迁移链：用新迁移删表，不修改已发布的旧迁移文件。
- Agent 行为变化需同步更新提示词，避免模型误用。

## 5. 约束与假设

- 仅 Android 移动端 + Web 端（frontend 为 Capacitor 套壳残留，仅改登录文案与页面标题，不做大改）。
- 视觉风格沿用 v0.1 风格 C「活力渐变」（紫 `#8B5CF6 → 粉 #EC4899`、浅紫底 `#F7F5FF`、深色底 `#171322`），本轮不重出整套风格原型，仅对新增/改动界面给出组件级说明（见 ARCH.md 第 5 章）。
- 圈子功能确认无在用用户价值，直接删除而非隐藏。
- FR-09 以调研结论为准，实施范围取决于用户选择。
