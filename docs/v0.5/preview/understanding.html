一句话理解

我理解你要的是：在「新增账单」弹层里加两个快捷：① 日期行旁边一个「同上次 08-15」chip，点一下就把日期设成上一笔记账的日期；② 备注输入框下面一排常用备注 chip，点一下填入备注（候选＝我手动收藏的 + 系统按历史频率自动推荐的）。

目标用户与场景

  • 谁：你自己（单人用 App 记账，伴侣各自记自己的账）。
  • 什么时候用：补记昨天的账、连续几笔都是同一天；备注反复是「早餐 / 地铁 / 买菜」那几个。
  • 解决什么问题：现在每开一次弹层日期都是「今天」，补记要手动翻日历；备注要一个字一个字重新打。

核心流程

1. 点 ＋ 打开新增账单
→
2. 输金额
→
3. 备注：点常用 chip 填入（或手打）
→
4. 日期：点「同上次 08-15」（或点日期行正常选）
→
5. 选分类 → 确认新增
第 3、4 步都是「一次点击即完成」，不再需要翻日历 / 重新打字。两步都可跳过，不点就走原来的流程。

两处新增的细节规则

位置规则
「同上次 HH-MM-DD」chip ① 值 = 我最近录入的那一笔账单的「日期」（按录入时间取最新一条，不限月份）；
② 只显示日期数字（例「同上次 10-06」），不写「昨天 / 前天」；
③ 点一下 → 日期框变成该日期，chip 变为选中态；随后仍可点日期行用日历改；
④ 没有任何历史账单时，chip 不显示；
⑤ 编辑一笔旧账单时同样显示，可一键改成上次日期；
⑥ 不会自动套用——新开弹层默认日期仍是今天。
常用备注 chips ① 候选 ＝ 我手动收藏的（★，排最前）+ 系统自动推荐的高频备注（去重、排除已移出的）；
② 自动推荐口径：最近 90 天内出现 ≥2 次、且属于当前所选分类的备注，按 出现次数↓、最近使用↓ 排序（★收藏的不受分类过滤，始终显示）；
③ 最多显示 8 个，超出不显示（一行横向可滑动）；
④ 点击 = 覆盖填入备注框（先清空再填）；
⑤ 长按 = 弹出选项「收藏到常用 / 从常用移出」；
⑥ 备注框右侧「＋收藏」：把当前输入的文字加入常用（输入为空或已在列表中时不可用）；
⑦ 空备注不进入候选。

关键数据字段

字段含义来源
last_date我最近录入的那笔账单的日期（YYYY-MM-DD）账单表按录入时间倒序取第一条
note备注文本（≤255 字）现有账单表字段，不改
source该候选是「我收藏的」还是「系统推荐的」收藏记录表 / 频率统计
count最近 90 天该备注出现的次数统计得出（仅用于排序）
kind收藏记录的类型：收藏 / 移出（移出的不再被推荐）新增的收藏记录表
账单本身的字段（金额 / 类型 / 分类 / 日期 / 备注）一个都不改；新增的只有「常用备注收藏记录」这一份数据。

我的假设（如果不对请直接说）

  • 「上一次」= 我最近录入的那一笔（按录入时间，不限月份），取其账单日期。
  • 常用备注 跟账号绑定、存在服务器，两个账号 各自独立、互不共享（你收藏的不会出现在伴侣的选择里）。
  • chip 只「填入」，不会自动提交，也 不会自动改分类 / 金额。
  • 新增弹层的默认日期仍是 今天，你不点 chip 就完全和现在一样。
  • 本次只改 App（mobile），Web 端（Capacitor 残留壳）不动。
  • 视觉沿用现在的「活力渐变」风格（紫 → 粉），chip 用现在的圆角胶囊样式，不新做一套风格。

暂不做

  • 常用金额 / 常用分类 / 常用收支组合的一键快捷键（本次只做「日期」和「备注」两项）。
  • 备注输入时的模糊下拉联想（先做成可见 chip，若不好用下个版本再加）。
  • 独立的「常用备注设置页」（管理入口先放在弹层里的长按菜单）。
  • Web 端同步、伴侣间共享常用备注、常用备注云端导入导出。

Q1：「上一次」到底指哪一笔？
A. 我最近录入的那一笔（按录入时间）✅ 已选 B. 当前月份列表里日期最近的那一笔 C. 固定就是昨天
差别：若我最近录的是「补记上月 20 号」的一笔，A 会给 20 号，B/C 会给别的值。
Q2：手动收藏的常用备注要不要和伴侣共享？
A. 各自独立，互不可见 ✅ 已选 B. 两人共享一份（谁收藏了另一个也能看到）
Q3：自动推荐的备注要不要跟着「收支 / 分类」过滤？
A. 不区分，全量按使用频率推荐（最简单） B. 按当前分类过滤 ✅ 已选 C. 按当前收支过滤（支出只推支出备注）
已选 B：选「餐饮」只推历史上记在餐饮类的常用备注；★收藏的始终显示、不受分类影响。切换分类时 chip 列表实时跟着变。
