# 需求文档：挖孔屏(灵动岛)状态栏沉浸式适配 v0.3

- 创建时间：2026-08-16 15:52
- 版本：v0.3
- 状态：已确认

## 1. 背景与目标

部分 Android 手机为挖孔/打孔屏（类似灵动岛），当前 App 顶部状态栏区域（含摄像头挖孔处）显示**白色**，与页面背景（浅紫渐变系/深色）不协调。原因：targetSdk 36（Android 15）强制 edge-to-edge，状态栏透明后露出的是窗口默认背景（白色），且内容/渐变被 SafeAreaView 下移未铺满顶部。

目标：沉浸式适配——登录/注册页紫粉渐变**铺满屏幕最顶部（含挖孔区域）**，状态栏图标白色；主界面状态栏区域显示**主题背景色**（浅紫/深色），不再露白；深色模式同步。

## 2. 功能需求

| 编号 | 需求描述 | 优先级 |
| --- | --- | --- |
| FR-01 | Android 主题：`windowBackground` 跟随明暗主题（浅色 `#F7F5FF` / 深色 `#171322`），替代默认白色；`windowLayoutInDisplayCutoutMode=shortEdges`（内容/背景延伸到挖孔区域） | 高 |
| FR-02 | 登录/注册页（AuthLayout）：紫粉渐变背景铺满到状态栏顶部（含挖孔），状态栏图标为白色（浅色渐变上必须白字） | 高 |
| FR-03 | 主界面（Tab 页及栈页）：状态栏区域显示主题背景色（浅紫/深色），各页面根容器补 `backgroundColor: theme.background`，不再露白 | 高 |
| FR-04 | 深色模式：windowBackground 深色变体 + 状态栏图标浅色；所有适配在深色下同样生效 | 中 |
| FR-05 | StatusBar 统一处理：`translucent` + 透明背景，由页面背景接管状态栏区域；图标颜色按页面顶部明暗自动切换（登录页白、主界面按主题） | 高 |

## 3. 非功能需求

- 兼容 minSdk 24：`windowLayoutInDisplayCutoutMode` 为 API 27+，需 values-v27 变体或 tools:targetApi 处理，低版本自动忽略。
- 不改动业务布局（仅背景/安全区处理），页面内容不被状态栏遮挡（SafeArea 仍保证内容可读）。
- 明暗主题切换即时生效。

## 4. 验收标准

- [ ] 浅色模式：登录/注册页渐变铺满顶部（含挖孔），状态栏图标白色；主界面状态栏区域为浅紫背景，无白色条
- [ ] 深色模式：登录页渐变铺满顶部；主界面状态栏区域为深色背景，状态栏图标浅色
- [ ] 挖孔屏（API 27+）内容/背景延伸到挖孔区域；非挖孔屏无回归
- [ ] 页面内容不被状态栏遮挡（表单、标题可正常显示/滚动）
- [ ] release APK 构建通过

## 5. 约束与假设

- 仅 Android（iOS 不在此需求范围）。
- 不改动业务功能与导航结构。
- 视觉以 v0.1 风格 C「活力渐变」为基准：主渐变紫 `#8B5CF6 → 粉 #EC4899`；浅紫底 `#F7F5FF`；深色底 `#171322`。
